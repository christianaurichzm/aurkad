The source code is licensed under Apache-2.0. That license covers the code -
it does not grant any right to the project name or logo.

## You may

- Say your game "runs on Aurkad" or "is built with Aurkad".
- Use the name to refer to this project accurately, in articles, talks and docs.
- Distribute unmodified copies under the project name.

## You may not, without written permission

- Use the name or logo as the name of your own product, service or fork.
- Use them in a way that suggests this project endorses or maintains yours.
- Register the name, or anything confusingly similar, as a trademark or domain.

A modified version must be distributed under a different name. This keeps the
name meaningful as a signal of what the official project actually is, which is
the only thing Apache-2.0 leaves the author.
